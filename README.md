# Dynamic Budget Tracker

A dynamic personal budget tracker built entirely in Excel. Navigate month-to-month with a single click and watch income, 18 expense categories, and savings balance update automatically, no add-ons, no macros to install, no external tools required.

## Overview

Most budget trackers either live in a static spreadsheet you have to manually update every month, or push you toward a subscription app. This project takes a different approach: a single Excel workbook with a navigation control that flips between months, recalculating every figure on the dashboard as it goes, income breakdown, expense categories, savings balance, and month-over-month percent change, all without leaving Excel or touching an add-on.

---

## Features

- **Month-to-month navigation** — arrow controls move forward and backward through the year, with every chart and figure updating instantly
- **18 expense categories** — granular enough to track real spending patterns, not just broad buckets
- **Automatic % change calculations** — see how each category moved compared to the prior month without manual math
- **Top 5 Expenses donut chart** — instantly surfaces where the month's money actually went
- **Full-year income and expense trend charts** — zoom out from the month view to see the year's trajectory at a glance
- **Real-time savings balance** — calculated automatically as income and expenses update
- **No add-ons required** — built entirely with native Excel functionality

---

## How It Works

1. Open the workbook and land on the current month's dashboard view
2. Use the navigation arrows to move to any month in the year
3. Enter or adjust income and expense figures for that month
4. Every visualization, the donut chart, trend lines, balance figure, and percent-change indicators, recalculates automatically
5. Switch back to the full-year view at any point to see how the month fits into the bigger picture

---

## Dashboard Breakdown

**Monthly View**
- Income streams for the selected month
- All 18 expense categories broken out individually
- Month-end savings balance
- Percent change vs. the previous month for income, expenses, and savings

**Top 5 Expenses**
- Donut chart ranking the month's five largest expense categories, so overspending is visible at a glance instead of buried in a list

**Full-Year Trends**
- Dual trend charts tracking income and expenses across all 12 months
- Useful for spotting seasonal spending patterns or checking whether savings are trending in the right direction over time

## Getting Started

1. Download `Dynamic_Budget_Tracker.xlsm` from this repository
2. Open it in Excel (macros enabled, since navigation controls rely on them)
3. Replace the sample income and expense data with your own figures
4. Use the navigation arrows to move through months and watch the dashboard update

## Why This Project

Budgeting tools often ask you to trust a third-party app with your financial data, or they lock useful features behind a subscription. This project shows that a fully interactive, dynamic budget dashboard, complete with navigation, automatic recalculation, and visual trend tracking, can be built with nothing more than Excel's native toolset. It's meant to be practical enough to actually use every month, not just a one-time template.
